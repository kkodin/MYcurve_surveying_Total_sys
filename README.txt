M_APP_001 保存・運用メモ

目的
曲線推進管理システム Vr015 の mobile 版を、スマホ内保存またはスマホアプリ風の運用で、ネットワークに接続していない状態でも使いやすくするためのフォルダです。

基本の使い方
1. index.html を開きます。
2. 「基本データ・作業メニューを開く」から作業を開始します。
3. 基線JSONを読み込む、または新規入力します。
4. 測量結果入力、水平誤差判定、グラフ、推力計算などへ進みます。
5. 作業後はブラウザ内保存だけでなく、必ずJSON保存も行ってください。

保存方式
- ブラウザ内保存:
  localStorage を使います。端末や同じブラウザで継続作業する時に便利です。
- JSON保存:
  現場記録、端末移行、バックアップ用です。作業後はこちらを必ず残してください。

オフライン運用
- このフォルダ内のHTMLは、外部ネットワークに依存しない構成です。
- フォルダ一式をスマホへコピーしてHTMLとして開く運用ができます。
- Service Worker によるホーム画面アプリ風運用は、file:// では登録されません。
- Service Worker を使う場合は、HTTPS、社内サーバー、GitHub Pages、またはスマホ内ローカルサーバーで一度 index.html を開いてから、ホーム画面へ追加してください。

フォルダ構成
- index.html: M_APP_001 の入口画面
- manifest.json: スマホアプリ風表示の設定
- service-worker.js: オフラインキャッシュ設定
- icon.svg: ホーム画面用アイコン
- 00_basic_input.html から 05_measurement_horizontal_error.html: 既存 mobile 版の作業ページ
- *.json: サンプル/検証用データ

注意
- ブラウザ履歴削除、端末交換、別ブラウザ利用ではブラウザ内保存が消える場合があります。
- 現場での正式保存はJSONファイルを優先してください。
- iPhone/Android のファイル管理アプリから直接HTMLを開く場合、端末やブラウザによりファイル読込やService Workerの動作が異なります。
